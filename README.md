## 功能概览

### 📝 数据录入

- **水**：用量(吨) + 单价 → 自动计算金额，额外录垃圾处理费，合计自动汇总
- **电**：用量(度) + 单价 → 自动计算金额
- **气**：用量(m³) + 单价 → 自动计算金额
- 年份/月份选择，重复记录会提示是否覆盖

### 📊 历史数据

- 按年份和类型筛选数据
- 每条记录可独立 **冻结/解冻**（冻结后不可修改删除）
- 支持批量冻结、解冻、删除选中
- 表格以色块区分冻结/未冻结状态

### 📈 统计分析（ECharts 图表）

- **月度趋势** — 折线图展示每月金额变化
- **用量对比** — 柱状图对比每月用量
- **费用分布** — 环形饼图展示各类占比
- **同比对比** — 当年 vs 上年同期对比柱状图
- 顶部展示汇总统计（总记录数、总费用、月均、最高月份等）

### ⚙️ 数据管理

- **导出备份** — 下载完整 JSON 数据文件
- **导入数据** — 上传 JSON 恢复数据
- **数据概览** — 显示总记录数和年份跨度
- **重置数据** — 清空所有记录（带二次确认）

### 🎨 科技感设计

- 深色霓虹主题（#060b18 基底 + #00d4ff 青色 + #7c3aed 紫色）
- 扫射扫描线、渐变发光边框、毛玻璃卡片效果
- 动画导航指示器、悬停发光效果
- 响应式布局、自定义滚动条
